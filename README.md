# bucu_vehiclekeys

> Vehicle Lock & Remote Keyfob System with Lockpicking and Engine Inhibitor for FiveM.

---

## 🌟 Overview

`bucu_vehiclekeys` ensures vehicle security with keyfob remote animations, headlight double-blinking, lockpicking minigame chance, and key sharing.

## 📦 Features
- **Keybind 'L'**: Toggle vehicle door locks from up to 15 meters away with fob click animation.
- **Lockpick Usable Item**: 75% success chance to unlock parked vehicles with snap chance.
- **Engine Hotwire Inhibitor**: Non-keyed vehicles cannot start without lockpicking.
- **Key Sharing**: `/givekeys` command to hand keys to nearby players.
- **Cross-Framework Bridges**: Bridges for `qb-vehiclekeys` and `wasabi_carlock`.
